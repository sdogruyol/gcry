# Wall-time sessions

`scripts/ab2.py`: every arm once per (rep, bench), random order per (rep, bench), host-wide lock held for the whole session. Wall = fork to wait4; timed section = the bench's own `in X s` (`run` only; Revcomp's 13 M-nucleotide Fasta input is built before it); user/sys/faults from `wait4`'s rusage. Ratios are per rep against the reference arm's run in the same rep, so a disturbed rep moves every arm together.
