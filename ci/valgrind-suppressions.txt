# Valgrind suppressions for Crystal runtime false positives.
# These are not gcry leaks — they come from the Crystal runtime / libraries.

{
   Crystal runtime thread initialization
   Memcheck:Leak
   match-leak-kinds: definite
   fun:malloc
   ...
   fun:*Thread#initialize*
}

   Crystal runtime signal handler

   ...
